# ARM64 汇编俄罗斯方块 简报
状态: 已确认（2026-10-14）

## 目标
在 macOS 上用纯 ARM64 汇编实现的、终端可玩的经典俄罗斯方块，作为作品展示项目。

## 用户与场景
- 你本人及任何拿到仓库的人，在 Mac 终端里构建后直接运行游玩
- 入口：命令行（`make` + 运行二进制）

## 范围
- 7 种标准方块，支持旋转（简单旋转，非 SRS）
- 键盘控制：左右移动、软降、硬降、旋转、暂停、退出、重开
- 消行计分，等级随消行数提升、下落加速
- 下一块预览
- 游戏结束画面与重开
- 终端 ANSI 彩色渲染，raw mode 无回显输入

## 不做
- 幽灵块、暂存(hold)、SRS 踢墙
- 音效、菜单、自定义配色
- Linux / 其他平台移植
- 高分持久化到文件

## 已定决定
- 平台：macOS ARM64 原生 —— 用户选择
- 目的：作品展示，代码质量与完成度优先 —— 用户选择
- 纯度：零 libc，只用系统调用，ld 直接链接 —— 用户选择
- 功能范围：经典完整版 —— 用户选择

## 验收样例
| 输入 / 操作 | 期望结果 |
|---|---|
| `make` 后运行二进制 | 终端进入 raw mode，出现带边框棋盘、下一块预览、分数与等级显示，方块自动下落 |
| 方向键移动/旋转，空格硬降 | 方块即时响应；硬降瞬间落底锁定，满行被消除且分数增加 |
| 堆到顶部 | 显示 GAME OVER，按 R 重开新局，按 Q 恢复终端原状态并退出 |
| 消行数达到升级线 | 等级 +1，下落速度明显加快 |

## 假设与开放问题
- 假设：汇编器用 Xcode 命令行工具自带的 `as`（NASM 不支持 macOS arm64），退出时正确恢复终端模式
- 假设：键位为方向键 + 空格（硬降）+ P（暂停）+ Q（退出）+ R（重开），无鼠标
- 假设：README 含构建与试玩说明（作品展示需要）；录 GIF/asciinema 可选、不作为必做
